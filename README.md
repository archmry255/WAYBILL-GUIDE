# Waybill Administrator Guide

Muongozo wa kazi za kila siku kwa Waybill Administrator - Geita Gold Mine (Security Department).

App hii inaonyesha kazi za leo, za wiki, na matukio ya mwezi (Ukaguzi wa Polisi, MPSA Sample Collection, Mikutano ya Robo Mwaka), na inaweza kusakinishwa kwenye simu kama app halisi (PWA).

Tovuti hii inafanya kazi kupitia GitHub Pages.
